# Vido4K Video Downloader

Deployable Next.js App Router project for `https://vido4k.aliwvide.com`.

## Deploy

1. Upload this project to GitHub or Vercel.
2. In Vercel, add this environment variable:

```txt
NEXT_PUBLIC_SITE_URL=https://vido4k.aliwvide.com
```

3. Deploy.
4. Submit this sitemap in Google Search Console:

```txt
https://vido4k.aliwvide.com/sitemap.xml
```

## Included

- Homepage video downloader UI
- Adsterra popunder script
- Adsterra global/social bar script
- Adsterra native ad container and script
- Smart link shown as a sponsored link
- robots.txt via `app/robots.js`
- sitemap.xml via `app/sitemap.js`
- FAQ, Contact, Terms, and Privacy pages
- Canonical URLs fixed for `https://vido4k.aliwvide.com`


## Latest change

When a user pastes a URL into the Video URL field, the File name field now automatically changes to the website/domain name, for example `https://example.com/video.mp4` becomes `example-com.mp4`.
